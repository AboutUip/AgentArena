中国象棋由红方和黑方对弈。红方先走，之后双方轮流走一步。

棋子走在线上。帅和将只在九宫里直走一格。仕和士只在九宫里斜走一格。相和象走田字，不能过河，田字中心有子时不能走。马走日，马腿被绊时不能走。车直走，路径上不能有子。炮直走，不吃子时路径要空着，吃子时中间必须隔一个子。兵和卒没过河只能向前一格，过河后可以向前或横走一格，不能后退。

帅和将不能在同一条直线上面对面，中间没有棋子也不行。

把对方走得没有合法步，并且正在将军，就是将死。没有合法步、也没有被将军，是困毙。将死和困毙都算走不动的一方输。

一方认输，另一方获胜。同一局面出现三次，这盘棋和了。连续反复将军造成循环的一方，这一方判负。双方一共走了一百二十步，其间没有吃子，也没有走动兵或卒，这盘棋和了。
